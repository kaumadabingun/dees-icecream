Publishing with GitHub Pages
----------------------------
1. Upload index.html to the root of your GitHub repository.
2. If the website uses a logo, upload the logo into an assets folder named exactly "assets".
3. Open your repository's Settings > Pages.
4. Under Build and deployment, select "Deploy from a branch".
5. Select branch "main" and folder "/(root)", then save.
6. Wait for GitHub Pages to finish publishing. Your site URL should appear on the Pages settings screen.

Note
----
The website is a static site. You do not need to set up a webhook.
